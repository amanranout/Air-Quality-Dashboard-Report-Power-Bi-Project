
# 🌍 Air Quality Dashboard – Power BI

An interactive **Power BI dashboard** designed to analyze and visualize air quality data, including **AQI, PM2.5, PM10, CO, NO₂, SO₂, and O₃**.

## 📊 Features

* AQI and pollutant analysis
* City/region-wise comparison
* Pollution trend analysis
* Interactive filters and visualizations
* KPI cards for quick insights

## 🛠️ Tools Used

**Power BI | Power Query | DAX | Data Cleaning | Data Visualization**

## 🎯 Objective

To provide clear and interactive insights into **air pollution levels and trends** for better data-driven understanding.
