# Air-Quality-Dashboard-Report-Power-Bi-Project
# Air Quality Dashboard – Power BI  Developed an interactive **Air Quality Dashboard in Power BI** to analyze AQI and major pollutants such as PM2.5, PM10, CO, NO₂, SO₂, and O₃. Used **Power Query, DAX, and data visualization** to identify pollution trends, compare air quality, and generate meaningful insights.
